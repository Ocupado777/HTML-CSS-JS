Nombre del proyecto: CRUD de Géneros Angular
Descripción: Aplicación cliente en Angular para administrar géneros de películas consumiendo una API REST
Tecnologías utilizadas: Angular 22, TypeScript, HTML5, CSS3, HTTP Client

Instrucciones para ejecutar:

npm install para instalar dependencias
npm start para iniciar la aplicación
Acceder a http://localhost:4200


Endpoints utilizados:

GET http://cine.runasp.net/api/Generos
POST http://cine.runasp.net/api/Generos
PUT http://cine.runasp.net/api/Generos/{id}
DELETE http://cine.runasp.net/api/Generos/{id}
